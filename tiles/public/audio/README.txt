Drop royalty-free / public-domain audio here to replace the synthesized beds:

  music.mp3  -> looping background music (e.g. a royalty-free 1940s big-band / swing track)
  crowd.mp3  -> looping casino room murmur / crowd chatter

As soon as a file named exactly music.mp3 (or crowd.mp3) exists in this folder,
the game uses it automatically and skips the synthesized fallback. No code change
or restart needed — just refresh. Levels are controlled by the in-game mixer
(volume icon -> Music / Crowd sliders).

Sourcing tip: use tracks explicitly licensed CC0 / public domain / royalty-free
(many 1940s big-band recordings are NOT public domain in all regions — check the
license before using).
